Face Match: Поиск двойника среди звезд

Этот проект использует сиамскую нейросеть **FaceNet** для сравнения вашего лица с базой данных 13 000 знаменитостей (LFW).

## Инструкция по запуску:
1. Установите зависимости: `pip install -r requirements.txt`
2. Скачайте датасет (https://www.kaggle.com/datasets/jessicali9530/lfw-dataset) и распакуйте папку `lfw-deepfunneled` в корень проекта (118Мб)
3. Положите свое фото под именем `me.jpg` рядом с кодом.
4. Запустите `main.py`.

Результат:
Программа выведет ТОП-3 похожих на вас звезды с указанием Евклидова расстояния.

В папке Photo находятся результаты сравнения известных лиц с базой данных. Файл Final9 - это мое фото :) лет 10 назад и файл Final10 - мое фото сделанное пару месяцев назад. Что интерестно, то попадается и там и там Альберто Акоста, но уже на 5% меньше сходства. Но и на десерт немного юмора: файл Final11 - это фото моей собаки.
