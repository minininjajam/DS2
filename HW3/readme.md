# 🐝 Queen Bee Detector & Tracker (YOLO)

Интеллектуальная система автоматического поиска и отслеживания пчелиной матки на видео. 

##  Особенности реализации
* **Двухэтапное обучение (Fine-tuning):** 
    1. Базовое обучение (100 эпох) для формирования общих признаков.
    2. Уточняющее дообучение (50 эпох) на специфическом датасете с использованием **Negative Samples** для устранения ложных срабатываний.
* **Интеллектуальный трекинг:** Применение алгоритма **BoT-SORT** для присвоения матке уникального ID и стабильного удержания цели в плотной группе пчел.
* **Кроссплатформенность:** Код адаптирован для запуска как в облаке (Google Colab), так и на локальных ПК (включая архитектуры без AVX2, например, AMD FX-6300).

## Результаты и метрики
Модель показала высокую избирательность и точность:
* **mAP50:** 0.777 (77.7%)
* **Precision (Точность):** 0.855 (минимальное количество ложных рамок)
* **Recall (Полнота):** 0.786 (уверенное нахождение объекта)
* **Confusion Matrix:** 22 верных определения против всего 4 ложных срабатываний на проверочной выборке.

## Технологический стек
* **Язык:** Python 3.11
* **Нейросеть:** Ultralytics YOLOv11 (Detection + Tracking)
* **Подготовка данных:** Roboflow (аугментация, управление датасетом)
* **Инструменты:** Google Colab, OpenCV, FFmpeg.
