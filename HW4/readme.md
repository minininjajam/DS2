# 🐝 Smart Honey Shop Bot (PyTorch)

Интеллектуальный Telegram-бот для «Медовой Лавки», построенный на базе полносвязной нейронной сети. Бот не просто отвечает по шаблонам, а классифицирует намерения пользователя, обрабатывает заказы и ведет учет продаж.

## 🚀 Основные возможности
*   **Нейросетевой чат-бот:** Классификация намерений (Intents) с использованием PyTorch.
*   **Умная корзина:** Возможность выбора нескольких товаров, суммирование заказа и расчет итоговой стоимости.
*   **Обработка опечаток:** Интеграция `FuzzyWuzzy` для понимания запросов с ошибками (например, "првет", "медок").
*   **Система логирования:** 
    *   `train_log.txt` — фиксация хода обучения сети (Loss/Accuracy).
    *   `bot_log.txt` — история диалогов с пользователями.
*   **Сбор данных:** Автоматическое сохранение заказов (`orders.csv`) и оптовых заявок (`questions.csv`).
*   **Гибкий каталог:** Разделение на категории (Мёд, Мыло, Свечи) с юмористическим описанием.
