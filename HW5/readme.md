# Pix2Pix Landscape Generator
Нейросеть (GAN) для превращения скетчей в реалистичные пейзажи.

### Как запустить:
1. Установите зависимости: `pip install -r requirements.txt`
2. Положите свои фото в `dataset/landscapes/`
3. Запустите обучение или тест через `python main.py`

### Особенности:
* Архитектура U-Net с Skip-connections.
* Дискриминатор PatchGAN.
* Автоматическая генерация скетчей из фото с помощью Canny Edge Detector.
-------------------------------------------------------------------------

## Особенности обучения и архитектуры

### 1. Система контрольных точек (Checkpoints)
В коде реализована полноценная система сохранения прогресса. Перед началом каждой сессии скрипт автоматически проверяет наличие файла весов `pix2pix_landscape.pth`. 
* **Загрузка:** Если файл существует, модель восстанавливает веса генератора, дискриминатора и номер последней эпохи.
* **Преимущество:** Это позволило обучить нейросеть на датасете из **4319 изображений** в несколько этапов, не теряя прогресс при перезапусках.

### 2. Процесс обучения и метрики
Обучение было инициировано с 0-й эпохи и приостановлено на 6-й для промежуточного тестирования. 

**Выписка из логов (Эпоха 6):**
* `Epoch 6 [0/4319]   Loss D: 0.0206  Loss G: 45.7803`
* `Epoch 6 [100/4319] Loss D: 0.0560  Loss G: 33.0946`
* `Epoch 6 [200/4319] Loss D: 0.0194  Loss G: 33.2007`
* `Epoch 6 [300/4319] Loss D: 0.0254  Loss G: 43.1026`
* `Epoch 6 [500/4319] Loss D: 0.0268  Loss G: 43.0201`
* `Epoch 6 [600/4319] Loss D: 0.0133  Loss G: 54.1477`
* `Epoch 6 [700/4319] Loss D: 0.0108  Loss G: 52.8619`
* `Epoch 6 [800/4319] Loss D: 0.0080  Loss G: 29.3552`

### 3. Анализ показателей
* **Loss D (0.008–0.05):** Крайне низкие значения ошибки дискриминатора подтверждают его высокую точность в сепарации реальных и генерируемых данных. Это создает жесткие условия для обучения генератора, минимизируя визуальный шум.
* **Loss G (29–54):** Колебания вызваны состязательной природой GAN, однако общее снижение Loss G до значения **29.35** на 800-м батче свидетельствует о качественном улучшении попиксельной схожести генерируемого пейзажа с оригиналом (L1-оптимизация).

## Доступ к данным и весам

### 1. Файл весов (Модель)
Обученные веса нейросети сохраняются в файл `pix2pix_landscape.pth` в корне проекта. 
* **Локальное расположение:** `./pix2pix_landscape.pth`
* **Использование:** При запуске скрипта файл подгружается автоматически для инференса (генерации) или продолжения обучения.

### 2. Датасет (Dataset)
В связи с большим объемом данных (**4319 изображений**), полная выборка вынесена в облачное хранилище.
* **Ссылка на Google Диск:** (https://drive.google.com/drive/folders/1Wk3cSH8eTjMXQW_0rT8eDVoU9JODG6Qg?usp=sharing)
* **Инструкция:** Скачайте архив и распакуйте содержимое в папку `./dataset/landscapes/` для корректной работы скрипта обучения.
Работа с изображениями (Input/Output)
Для проверки работы обученной модели используется механизм инференса, реализованный в функции test_my_drawing.
Входной файл (my_sketch.jpg):
Файл должен располагаться в корневой директории проекта.
Нейросеть ожидает контурный рисунок (черные линии на белом фоне).
Программа автоматически изменит размер изображения до 256x256 пикселей и нормализует цветовые каналы перед обработкой.
Выходной файл (result_landscape.jpg):
Результат генерации сохраняется в корень проекта под именем result_landscape.jpg.
Изображение представляет собой полноцветную интерпретацию скетча, где нейросеть восстановила текстуры неба, травы, гор или воды на основе паттернов, выученных из 4319 фотографий датасета.
Для наглядности работы изображение result_landscape сгенерировано на 3 эпохе (4я если от 0), а result_landscape2 на 6 эпохе (7я если от 0).
