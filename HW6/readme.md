VibeSynth AI: Интеллектуальный музыкальный рекомендатор

Проект представляет собой систему подбора музыки на основе эмоционального состояния пользователя («вайба»). Система использует комбинацию трансформеров для смыслового поиска и рекуррентных нейросетей для классификации жанров.
Описание файлов проекта

Программный код 
*   `bot.py` — Основной интерфейс. Содержит логику Telegram-бота, обработку команд, кнопок и интеграцию с нейросетями.
*   `prepare.py` — Скрипт первичной обработки данных. Очищает датасет от дубликатов и превращает тексты в математические векторы.
*   `train_lstm.py` — Скрипт обучения классификатора. Содержит архитектуру нейросети LSTM и процесс её тренировки на жанрах.

Данные и Модели 
*   `dataset.csv` — Исходная база данных музыкальных треков (названия, артисты, жанры).
*   `processed_music.csv` — Очищенная и структурированная база данных, готовая для быстрого поиска ботом.
*   `music_embeddings.npy` — Векторные представления (числовые "отпечатки") всех песен. Именно по ним ИИ находит похожую музыку.
*   `my_lstm_model.pth` — Сохраненные "веса" (мозги) обученной нейросети. Позволяет боту мгновенно угадывать жанр без переобучения.

Конфигурация и Ресурсы
*   `requirements.txt` — Технический список всех библиотек (PyTorch, Aiogram и др.), необходимых для корректной работы проекта.
*   `welcome.gif` — Анимированное приветствие, которое пользователь видит при запуске бота (команда /start).
*   `README.md` — Инструкция и описание проекта (то, что вы читаете сейчас).

Обучение и Датасет
* Объем данных: Нейросеть LSTM обучена на полном наборе данных, содержащем **114 000 уникальных музыкальных композиций**.
* Разнообразие: Обработано более 120 различных музыкальных жанров.
* Глубина анализа: Для классификации использовался корпус текстов из 15 000 наиболее частотных слов в названиях треков.
