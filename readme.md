# Прогноз температуры по странам 🌍

Этот проект использует машинное обучение для анализа исторических данных о температуре и предсказания будущих значений.

## 🚀 Функционал
* Загружает актуальные данные из GitHub.
* Обучает модель **RandomForestRegressor** индивидуально для выбранной страны.
* Рассчитывает точность прогноза (R2 и MAE).
* Строит график прогноза на выбранный пользователем год.

## 🛠 Технологии
* Python 3
* Pandas, Scikit-learn, Matplotlib

## 📋 Как запустить
1. Откройте файл в [Google Colab](https://colab.research.google.com).
2. Запустите все ячейки.
3. Введите название страны (например, `Russia`) и год для прогноза.
