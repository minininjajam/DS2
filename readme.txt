Универсальный инструмент на Python для прогнозирования средней температуры в любой стране мира на основе исторических данных (1750–2015 гг.).

 Особенности
 Машинное обучение: Используется алгоритм `Random Forest Regressor` для выявления сезонных циклов и климатических трендов.
 Интерактивность: Пользователь сам выбирает страну и интересующий его год для прогноза.
 Аналитика: Расчет метрик точности (MAE, R^2) для каждой выбранной локации.
 Визуализация: Построение графика сезонных колебаний температуры.
